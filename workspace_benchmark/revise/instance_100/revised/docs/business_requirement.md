In network communication services, routing cost plays an important role. The bandwidth communication table between several communication nodes has been extracted into a CSV file. If two nodes cannot be directly connected, the corresponding bandwidth is $0$. It is required to establish a link between node A and node E that must pass through service node C (without loops). The routing cost of a direct connection between any two nodes is defined as `100 - bandwidth`. The total routing cost of a link is the sum of the costs of all direct connections it uses. Please refer to the corresponding CSV files in the data folder for specific parameter values and propose a reasonable link arrangement to minimize the total routing cost of this link and find out this minimum total cost.
