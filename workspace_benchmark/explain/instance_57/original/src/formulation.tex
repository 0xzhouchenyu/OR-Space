\section*{Sets and Indices}

\begin{itemize}
    \item $J=\{1,2,3\}$: set of orders, indexed by $j$.
    \item $S=\{1,2\}$: set of standard roll widths, indexed by $s$.
    \item For each $s \in S$, let $P_s$ be the set of all feasible cutting patterns for standard width $s$, indexed by $p$.
\end{itemize}

A pattern $p \in P_s$ is a vector
\[
a_{jsp} \in \mathbb{Z}_{\ge 0} \qquad (j \in J),
\]
where $a_{jsp}$ is the number of strips of order $j$ cut side-by-side from one unit length of a roll of standard width $W_s$, satisfying
\[
\sum_{j \in J} w_j a_{jsp} \le W_s,
\]
and excluding the all-zero pattern.

\section*{Parameters}

\begin{itemize}
    \item $w_j$: required width (meters) for order $j$.
    \item $L_j$: required length (meters) for order $j$.
    \item $W_s$: available standard roll width (meters) for roll type $s$.
\end{itemize}

For instance 57:
\[
(w_1,w_2,w_3)=(0.5,\,0.7,\,0.9), \qquad
(L_1,L_2,L_3)=(1000,\,3000,\,2000),
\]
\[
(W_1,W_2)=(1,\,2).
\]

Define the total required area
\[
A^{\mathrm{req}}=\sum_{j\in J} w_j L_j.
\]

\section*{Decision Variables}

For each standard width $s \in S$ and pattern $p \in P_s$:
\[
x_{sp} \ge 0 \qquad \text{(code: \texttt{x\_vars[(idx,i)]})}
\]
where $x_{sp}$ is the length of standard-width roll $s$ cut according to pattern $p$.

\section*{Objective}

The implemented model minimizes total area used:
\[
\min \sum_{s\in S}\sum_{p\in P_s} W_s\,x_{sp}.
\]

Since $A^{\mathrm{req}}$ is constant, this is equivalent to minimizing waste area
\[
\min \left(\sum_{s\in S}\sum_{p\in P_s} W_s\,x_{sp} - A^{\mathrm{req}}\right),
\]
and the code reports
\[
\text{waste}=\sum_{s\in S}\sum_{p\in P_s} W_s\,x_{sp}-A^{\mathrm{req}}.
\]

\section*{Constraints}

For each order $j \in J$, the total produced length must meet demand:
\[
\sum_{s\in S}\sum_{p\in P_s} a_{jsp}\,x_{sp} \ge L_j
\qquad \forall j \in J.
\]

Variable domains:
\[
x_{sp}\ge 0
\qquad \forall s\in S,\; p\in P_s.
\]

\section*{Notes on Implementation}

\begin{itemize}
    \item The model is a continuous cutting-stock-style master LP. Pattern variables are continuous, not integer, because the code allows arbitrary nonnegative real values for \texttt{x\_vars[(idx,i)]}. This matches the assumption that roll length is unlimited and can be spliced.
    \item Patterns are generated exhaustively in advance for each standard width $W_s$ by enumerating all nonnegative integer combinations of order widths that fit within $W_s$:
    \[
    \sum_{j\in J} w_j a_{jsp} \le W_s.
    \]
    The all-zero pattern is omitted.
    \item No pattern-reduction, column generation, or integrality restriction is used. The full enumerated LP is then solved with the configured LP solver interface.
    \item The code minimizes total area used directly; waste is computed afterward by subtracting the constant total required area.
    \item Because demand constraints are ``$\ge$'' rather than equality constraints, overproduction is allowed if it helps minimize total area under the available patterns.
\end{itemize}
