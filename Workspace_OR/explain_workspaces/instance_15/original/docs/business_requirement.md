A certain factory needs to use a special tool over multiple planning stages. At each stage, a specific number of specialized tools are required. After each stage, all tools used must be sent for repair before they can be reused. There are two repair methods: one is slower and cheaper but takes longer to return, while the other is faster and more expensive. If the repaired tools cannot meet the needs, new ones must be purchased. This special tool will no longer be used after the final stage. Please refer to the corresponding CSV files in the data folder for specific parameter values.
